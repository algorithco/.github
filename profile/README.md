## About

**Algorith** is an engineering organisation based in **Uzbekistan**, focused on building reliable, secure and scalable digital products.

We design and operate production-grade systems — from messaging platforms and payment infrastructure to developer tools and experimental web technologies.

Our goal is simple: **ship future-ready technology with engineering discipline.**

## How we work

- **Security first** — isolated services, secret scanning, least-privilege access
- **Production mindset** — healthchecks, observability, documented environments
- **Clean architecture** — micro-services, reproducible builds, versioned releases
- **Open engineering** — clear documentation and maintainable code

> We value small, senior teams, fast iteration and long-term maintainability over shortcuts.
